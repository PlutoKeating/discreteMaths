# 离散数学学习站点重构设计规格书：以真题为第一性原理的 Causally 渐进式叙事体系

- **日期**：2026-11-24
- **重构范围**：
  1. 全站阅读体验与视觉系统（`src/styles.css`、`src/Home.jsx`、`src/components/CourseReader.jsx` 等）
  2. 第 1 门课 `/Logic-and-Proof/`（以 **Midterm Test 01 · 60 分** 为第一性原理，覆盖 Ch1.1–1.6 & Tutorial 01–03）
  3. 第 2 门课 `/Relation/`（以 **Midterm Test 02 · 76 分** 为第一性原理，覆盖 Ch2.1–2.3, Ch9.1–9.3, Ch9.5–9.6 & Tutorial 04–06）
  4. 两门课配套的离线纯 Markdown 渐进式讲义（`Logic-and-Proof/Midterm-Review-Guide.md`、`Relation/Midterm-Review-Guide.md`）

## 1. 为什么推倒重做（Intent & Why）

上一版按教材知识分类把定义、6 大性质总表、8 套模板直接端给读者，导致零基础读者一进门就被密集的专业名词、红绿考频徽章和高饱和立体卡片淹没——**在还没有感受到“遇到了什么麻烦”之前先背名词，本质上就是无意义的名词堆叠**。

本次重构融合两件事：
1. **向 `learn.causally.xyz/math-series/` 学习渐进式叙事灵魂与沉静气质**：
   - 每一节标题都是一个大白话追问，而不是教材章节名；
   - **水到渠成才起名（Earned Vocabulary）**：永远先拿一个具体可试的小情境（两个开关、两台机器、一张 $3\times 3$ 方格表、先后手选数字）让读者亲眼看到矛盾或规律，等那个性质已经在读者脑子里长出来之后，才轻轻点破：“数学上和英文考卷里，把这件事叫作 **自反（reflexive）**”；
   - 短段落、对话式停顿追问（“先停一下……你会同意吗？……试着换个数看看”）、预测后再动手做实验、分层折叠练习（`提示` → `对照解法` → `再改一个条件`）。
2. **以真实考卷（Test 01 / Test 02）作为整门课的第一性原理**：
   - 与纯通识数学课不同，我们的读者有一个极明确的刚需：**从一点都不懂，在最短时间内具备独立拿下纯英文考卷的能力**。
   - 因此，我们**彻底抛弃教材/PPT 的学科目录顺序**，直接把真实考卷（Test 01 的 5 道题 60 分、Test 02 的 5 道题 76 分）作为生长主干：开篇把真题摊在桌上说明白我们要攻克哪几个具体任务；每一幕只生长出攻克当前那道真题所必需的最小概念链；每走完一两节就当场把对应真题拿下来，并配一个克制清晰的「**考场英文怎么落笔**」拆句框；而老师 PPT / Tutorial 里未在期中卷直接露面、但期末可能变式考查的近亲概念，全部化入每节末尾折叠的「**再改一个条件**」与「**选读**」中，做到**主线零冗余、考纲零遗漏**。

## 2. 目标、非目标与反目标（Goals, Non-Goals, Anti-Goals）

### 2.1 目标（Goals）
1. **彻底消除“教辅名词表堆砌感”**：两门课全部改写为 Causally 式的**问题驱动连续长卷**（Logic 设 **4 幕 · 7 问**，Relation 设 **4 幕 · 12 问**）。
2. **以真题为第一性原理的完整闭环**：零基础读者顺着 01 读到最后一节，不需要跳标签页，就能从零独立解出 Test 01（60 分）和 Test 02（76 分）的每一小问，并掌握标准英文证明/解释落笔句式。
3. **100% 保留并合理安放老师 PPT 与 Tutorial 01–06 全部考点**：核心链在正文自然长出；近亲延伸考点全部装进节末折叠的 `再改一个条件` 或 `选读 · ...` 中。
4. **Causally 式阅读器与本机学习记录**：
   - 桌面左侧常驻分幕问题目录 + 阅读进度条（`X / N 节已读`，窄屏 `<= 900px` 自动转为右侧抽屉目录）；
   - 顶部简洁面包屑导航 + 右侧三个安静工具入口：`原卷双语对照`、`术语速查`、`我的记录`（支持本机 `localStorage` 保存各节已读状态与思考笔记，两门课隔离存储键 `dismath.logic.v2` 与 `dismath.relation.v2`，支持一键导出个人 Markdown 笔记）；
   - 每个交互实验前必有一句预测追问；每节末必有折叠实战练习（`提示` → `对照满分写法` → `再改一个条件` → `我的理由与笔记`）。
5. **沉静温润的纸感编辑部视觉（Visual Calmness）**：参考 Causally 数学课色板（温润纸底 `#f6f5f0`、米白卡片 `#fffefa`、深松墨字 `#22312b`、松石绿强调 `#24634d`、柔和细边框 `#dcded6`，并提供舒适深色模式），砍掉 3D 浮雕斜块、切角卡片和刺眼的大号红绿徽章。

### 2.2 非目标（Non-Goals）
- 不在本轮建设 `Counting/` 与 `Graph/` 正文（首页保留其“整理中”卡片，并统一到新视觉风格）。
- 不新增任何第三方 npm 依赖，不写入任何新的 `.pdf` 文件。
- 不做账号登录或云端同步，学习记录仅保存在当前浏览器本地。

### 2.3 反目标（Anti-Goals）
- **严禁先抛定义再举例**：任何专业术语在它解决的具体困境出现之前，不得提前作为黑体定义端出。
- **严禁在主线正文中连续抛出超过 2 个新名词而不给具体小算例缓冲**。
- **严禁破坏英文应试精准度**：口吻亲切白话绝不等于数学含糊——所有符号优先级、量词作用域、Slide 45 复合矩阵左右顺序、整数域自反性、子集极值与全集上下界边界、格的唯一上下确界等得分命门必须比原版讲得更透彻。

## 4. 视觉与交互体验详细设计（UI & Experience Spec）

### 4.1 设计令牌（`src/styles.css`）
- **浅色模式（默认纸感）**：
  - `--bg: #f6f5f0`（温润书页底），`--paper: #fffefa`（内嵌教具/练习卡底），`--soft: #ecefe8`（柔和底衬）
  - `--fg: #22312b`（深墨松绿正文），`--muted: #627067`（次级说明），`--line: #dcded6`（1px 细线）
  - `--accent: #24634d`（沉静松绿主色），`--accent-soft: #e6efe9`
  - `--warm: #9e472a`（克制的赭石强调，用于关键转折点与易错提醒，替代刺眼大红），`--ok: #24634d`
- **深色模式（跟随系统 `prefers-color-scheme: dark`）**：
  - `--bg: #151917`，`--paper: #1d2320`，`--soft: #252d29`，`--fg: #e7ebe8`，`--muted: #9aa7a0`，`--line: #313b36`，`--accent: #6ec4a3`，`--warm: #f09a7e`
- **排版尺度**：
  - 正文栏最大阅读宽度 `43rem`（约每行 34–38 个汉字），字号 `16.5px`（手机 `15.5px`），行高 `1.9`，段间距 `1.15em`。
  - 数学公式块 `.katex-display` 采用干净的左对齐或居中纸白衬底框，超宽时局部平滑滚动，绝不撑破手机视口。

### 4.2 页面骨架（`CourseReader.jsx`）
1. **吸顶极简页眉（`.learning-header`）**：
   - 左侧面包屑：`离散数学学习空间`（回 `/`） `›` 当前课程名；
   - 右侧工具按钮：`原卷对照`、`术语速查`、`我的记录`、以及窄屏才显示的 `阅读目录` 按钮；
   - 底部 2px 阅读滚动进度细线。
2. **双栏主体（`.course-layout`）**：
   - **左侧常驻阅读目录（`aside.course-sidebar`，宽 `268px`）**：
     - 顶部显示课程核心追问、`已读 X / N 节` 细进度条；
     - 按 `第 1 幕`～`第 4 幕` 分组列出编号问题标题（如 `01 写答案范围时，为什么多套一层花括号意思就全变了？`），当前阅读小节高亮，已标记已读的小节右侧亮起小圆点。
   - **右侧连续阅读主栏（`main.course-main`）**：
     - **课程开篇（Hero + 真题地图 + 两道开篇小自查）**：先交代本模块面对的那张真实考卷（Test 01 / Test 02）到底问了哪几件事，配两道零门槛直觉自查题（先想一想，点开看思路）。
     - **分幕导语（`section.stage-intro`）**：交代这一幕准备攻克考卷上的哪道题（多少分），以及我们打算从什么日常小问题出发。
     - **问题章节（`section.chapter#s01`…）**：
       1. 编号 + 问题式标题；
       2. 渐进式白话正文（短段落 + 追问 + 公式自然浮现 + 首次定名中英粗体 + 英文术语轻虚线可点查）；
       3. **交互教具（`<figure class="lab-box">`）**：顶部带一句明确的「先猜一猜 / 试一试」任务引导，下方接零依赖 React+SVG 交互实验；
       4. **考场英文落笔框（`<aside class="exam-box">`）**：当本节拿下一道（或几小问）真题时，并排给出真题英文原句与考场满分英文作答模板，并用一句大白话点破阅卷人看哪几个词给分；
       5. **节末折叠选读（`<details class="optional-reading">`）**（按需出现）：安放课件中不阻碍主线的延伸概念；
       6. **节末折叠实战练习（`<details class="chapter-practice">`）**：包含一道紧扣本节的练习题、`给我一点提示`（折叠）、`对照满分解法`（折叠）、`再改一个条件`（覆盖 Tutorial/PPT 变式）及 `我的理由与笔记`（自动存入本机 `localStorage`）；
       7. **已读切换按钮（`标记这一节已读`）**。
3. **三个按需滑出抽屉/弹窗（不打断阅读流）**：
   - **原卷双语对照抽屉**：完整展示 `Midterm-Test-01` 或 `Midterm-Test-02` 英文原题、逐句中文翻译、分值与“跳到讲解小节”快捷链接，附原版 Markdown 折叠查看。
   - **术语速查抽屉**：实时搜索中英术语、释义，点击“定位到正文讲解处”可直接滚到对应章节。
   - **我的记录抽屉**：汇总当前课程已读小节与各节手写笔记，支持**一键下载 `.md` 学习笔记**与二次确认清空。

## 5. 两门课程的分幕章节与考点完整映射表

### 5.1 第 1 门课 `/Logic-and-Proof/`（主干：Midterm Test 01 · 60 分）

- **课程主标题**：一句话什么时候算真，一段话凭什么推得出来？
- **副标题 / 核心契约**：从零读懂逻辑符号，拿下 Test 01 全部 60 分与英文证明套路
- **开篇自查**：① 承诺“考 90 分就请吃饭”在考 80 分时算不算违约？② “有一个万能数配谁都得 10”与“给谁都能配成 10”差在哪？

| 幕次 | 章节号与问题式标题 | 当场攻克的 Test 01 真题 | 水到渠成引出的核心概念 | 内嵌交互实验 & 节末「再改一个条件 / 选读」覆盖的课件延伸点 |
|---|---|---|---|---|
| **第 1 幕**<br/>把真假算清楚（15 分） | **01** “如果……那么……”什么时候才算说了假话？ | 为 Q1, Q2, Q5 打地基 | 命题、真值、$\neg/\land/\lor$、条件语句 $p\to q \equiv \neg p\lor q$、逆否与原式等价 | **实验 1：承诺跳票与蕴含探针**（拨动开关验证 $p\to q$ 与逆/否/逆否真值）<br/>*选读*：双条件 $\leftrightarrow$、异或 $\oplus$、“only if / necessary / sufficient” 英文句式拆解、运算符优先级 |
| | **02** 考卷禁止列真值表时，凭什么说两句话意思完全一样？ | **Q2a, Q2b**（10 分） | 逻辑等价 $\equiv$、提公因式（分配律）、拆括号变号（德摩根律）、输出律 | *练习与改条件*：不等价时如何用一行赋值交出反例（Tutorial 01 Q3）；永真式与矛盾式、吸收律与否定律速查 |
| **第 2 幕**<br/>加上范围与先后手（22 分） | **03** 谁先出牌、谁后出牌？一局游戏看穿嵌套的“任意”与“存在” | **Q4a–d**（8 分）+ **Q2c**（5 分） | 谓词 $P(x)$、论域 domain、$\forall$ 与 $\exists$、量词先后顺序博弈、非空域条件与空真 | **实验 2：先后手量词博弈台**（亲自扮演 $\exists$ 或 $\forall$ 在 $x+y=10$ 与 $xy=0$ 中出牌）<br/>*改条件*：把整数域换成正整数域 $\mathbb{Z}^+$，Q4c 答案还成立吗？ |
| | **04** 把英文句子翻成符号时，为什么“每个……的人”绝不能配“且”？ | **Q1a**（9 分，含原卷 `-3` 复盘） | $\forall$ 配 $\to$、$\exists$ 配 $\land$、量词作用域 scope、自由变量陷阱 | *改条件与选读*：量词德摩根律逐层取反（Tutorial 02 Q8）；用 $\exists$ 与 $\forall$ 写出“恰好有一个（uniqueness quantifier $\exists!$）” |
| **第 3 幕**<br/>辨别真推理与冒牌货（15 分） | **05** 顺着线索往下推，哪一步铁证如山，哪一步只是错觉？ | **Q1b i, ii, iii**（15 分，含原卷 `-5` 复盘） | 有效论证 valid argument、UI / EG、Modus Ponens、Modus Tollens、否定前件与肯定后件谬误 | **实验 3：Bob·Noah·Jessica 推理链与反例制造机**（追踪可推链条，或一键拨出前提全真但结论为假的反例）<br/>*选读*：假言三段论、析取三段论、EI（新常量限制）与消解律（Tutorial 03 Q1–Q3） |
| **第 4 幕**<br/>自己动笔写英文证明（13 分） | **06** 正着算要开根号卡住了，为什么掉个头立刻畅通无阻？ | **Q5**（5 分：$n^2$ 偶 $\Rightarrow n$ 偶） | 直接证明、逆否证明 contraposition、反证法 contradiction、奇偶定义展开与收尾 | *改条件与选读*：分情况证明 proof by cases（绝对值/奇偶）、穷举证明，以及反证法证 $\sqrt{2}$ 是无理数（Tutorial 03 Q4–Q9） |
| | **07** 不仅要说明“找得到”，还要证明“绝没有第二个”，该怎么下笔？ | **Q6**（8 分：带余除法存在唯一性，复盘手写 `唯一的?`） | 存在性构造（floor 向下取整 / 良序集最小元）+ 唯一性夹逼模板（设两个推相等） | **图解：数轴上的 $nq$ 刻度尺与余数窗口 $[0, n)$**<br/>*改条件*：实数上 $a\neq 0$ 时 $ar+b=0$ 解的存在唯一性（Tutorial 03 Q10） |

### 5.2 第 2 门课 `/Relation/`（主干：Midterm Test 02 · 76 分）

- **课程主标题**：怎么把对象配成对、连成网、分好类、排出上下级？
- **副标题 / 核心契约**：从零看懂集合、函数与关系矩阵，拿下 Test 02 全部 76 分
- **开篇自查**：① 盒子 `{∅}` 里面是空的，还是装着一件东西？② 如果 $A$ 认识 $B$、$B$ 认识 $C$，$A$ 一定认识 $C$ 吗？换成“拥有一模一样的朋友圈”呢？

| 幕次 | 章节号与问题式标题 | 当场攻克的 Test 02 真题 | 水到渠成引出的核心概念 | 内嵌交互实验 & 节末「再改一个条件 / 选读」覆盖的课件延伸点 |
|---|---|---|---|---|
